# 玩法说明

《抽象大乱斗》包含三个独立模式。主入口为根目录的 index.html，全部玩法可以通过静态网页运行。

## 抽象格斗

横版即时格斗，支持1V1、2V2、同键盘双人与训练场。2V2可由一名玩家带CPU队友迎战两名CPU；电脑双人可共同对战CPU，或各带一名CPU分队对战。

1P使用A/D移动，W或空格跳跃，S防御；J/K轻重击，U/I/O技能，L必杀。2P使用方向键与数字小键盘1/2/4/5/6/3。角色随移动改变朝向，可越过对手后转身攻击。

「联网对战」支持两台机器在同一局域网内 1V1：一方运行 `npm run dev` 或双击 `start.bat` 作为服务器，双方打开其局域网地址，创建房间并以四位房间码加入。双方各自选人、都点开打后同步开始；场景由房主选择，只有房主可暂停，双方都点再来一局即重开；重新选人会带双方回到选人界面且房间保留，换角色后可直接再次开打。对手机器上 WASD + J K U I O L 与方向键+小键盘通用。断线自动重连并续战，页面刷新也能凭房间码恢复；具体使用见 [README](../README.md#局域网联机)，实现见 [开发指南](DEVELOPMENT.md)。

手机提供触控方向盘和技能键，支持斜向跳跃，推荐横屏。手机支持单人人机与训练场。战斗暂停时可点击画面中央继续。

角色普攻、技能、投掷、召唤与变身使用对应动画和道具。音乐在首次用户操作后启动，失焦或后台时暂停。

## 抽象回合战

每队四个位置。选角时可点击角色或拖动交换站位；战场在上方，技能和执行按钮在下方。可直接点击战场中的合法目标，再确认执行。

自由对战和同屏轮流均由玩家选择双方四人，角色需在本队内不同；同屏轮流分别标为1P与2P。五战远征由玩家选择四人小队，连续挑战自动生成的对手，战后可恢复、选择强化并在营地换位。

普攻获取能量，特色技能消耗能量，满100能量可使用必杀。前排保护、弱点和破绽影响行动与伤害。支持自动战斗和动画速度调整，远征进度保存到当前浏览器。

## 抽象自走棋

每场由1名玩家与7名CPU参加。初始60生命、8金币、3人口；准备阶段没有倒计时。随机五格商店购买棋子，部署到棋盘后自动战斗。角色在同一棋盘上连续跑动、碰撞、起招和受击。

开始页提供新建赛事和继续赛事。有未结束的本地存档时，棋盘展示保存的玩家角色和站位；没有存档或赛事已结束时，展示空场景。返回开始页会暂停当前战斗，继续后恢复。

3个一星同名合二星，3个二星同名合三星。1至5费角色分别有24/20/18/12/10张共享库存；商店展示时先预留卡牌，刷新、出售和淘汰会返还相应原始张数。合成不会创造额外卡牌。

刷新商店2金，花4金购买4经验，每轮免费2经验，最高8人口、9格候补。战后下轮获得基础5金，胜利额外1金；开战时每10金带来1利息，最多3金。连胜或连败3场增加1金，5场增加2金。

一星按原价售出，二星为3倍原价减1，三星为9倍原价减3。失败扣血为2加轮数除5向下取整，再加敌方存活数量（最多5）；平局扣4。玩家生命归零即按淘汰顺序结算，赛事最多24轮。

点按或拖动棋子进行部署，放下后自动取消选择；拖到商店出售，长按查看浮动资料。商店旁显示金币，羁绊和赛况下方也有开战入口。手机上的羁绊与赛况面板默认折叠，内部所有已激活项优先排列，点具体羁绊可查缺少的角色。

一键布阵综合单角色属性、星级、技能、承伤和实际激活羁绊，比较所有满人口组合。同名不增加羁绊人数，候补不贡献场上加成。推荐可继续手动调整，不保证对所有对手获胜。

选定阵容后，近战和坦克优先分布在前排，游击偏向侧翼，中程在后方支援，远程优先后排两翼。玩家自动布阵与CPU采用相同规则。远程普攻会在射程内出手，近战招式仍需靠近目标；远程普攻不会持续击退近战角色。

战斗30秒后伤害逐渐增加、治疗降低，45秒后仍未分胜负按剩余生命比例比较。奇数存活玩家可与其他棋手的镜像交战，镜像来源不会获得重复收益。CPU通过同一商店、金币和战斗规则行动。

详细规则见 [数值设计](BALANCE.md)、[角色手册](ROSTER.md) 和 [羁绊手册](RELATIONSHIPS.md)。

## 存档、音乐与场景

三个模式的音乐独立，场景可固定选择或随机。格斗和回合战共有13张场景；自走棋专用六张风景棋盘，分别为雪山棋台、森语棋庭、熔岩棋狱、云阙仙台、深海棋宫、霓虹棋域，透明格线叠在环境图上。共有18首Web Audio程序合成配乐，不需要下载远程音频。

回合战远征与自走棋赛事独立保存到当前浏览器。自走棋战斗前保存准备状态，战后保存下一轮收益状态；新开赛事会覆盖原赛事。改变域名、设备或清除浏览器数据，不会自动保留原存档。

项目支持本地单人、CPU、同屏与局域网双机联机（格斗模式），目前没有互联网实时联机匹配。
