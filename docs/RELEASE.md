# 1.2.0 · 局域网双机联机

发布日期：2026-09-18。

格斗模式新增「联网对战」：两台机器在同一局域网内 1V1 对战。采用延迟式确定性锁步，两台机器各自运行完整模拟，线上只传按键掩码；一方运行 `npm run dev`（或双击 `start.bat`）作为服务器，双方打开局域网地址，以四位房间码创建或加入房间。

双方各自选人并点开打后同步开始；场景由房主选择，只有房主可暂停，双方都点再来一局即重开。对手机器上 WASD + J K U I O L 与方向键+小键盘通用，手机触屏自动映射。

断线自动重连并续战：房间在双方全部离开前持续保留，掉线方自动退避重连，页面刷新也能凭房间码恢复；主机以完整状态快照对齐重连方，中转按活跃度接管死亡连接的槽位。状态哈希按 1e-4 容差比对，不同浏览器（Chrome 系、Firefox 等）可直接联机，连续两次不一致才中止。

`npm run play` / `start.bat` 一键启动：自动打开浏览器、端口占用自动顺延、页面心跳保活并在全部页面关闭约一分钟后自动退出，窗口中输入 `stop` 可随时手动关闭。联机使用说明见 [README](../README.md#局域网联机)，协议与确定性约束见 [开发指南](DEVELOPMENT.md)。

测试新增锁步回归套件（双实例 600 步哈希一致、mimic 借招确定性、快照续战）与端到端中转套件（大厅、对局、掉线重连、僵尸槽位接管）。

# 1.1.0 · 自走棋场景、存档展示与布阵更新

发布日期：2026-09-09。

自走棋加入开始页：有未结束存档时展示玩家实际阵容与站位，并可继续赛事；无可继续存档时展示空棋盘。

新增六张自走棋专用风景棋盘，支持固定选择和默认随机，透明格线覆盖在环境图上。场景分别为雪山、森林、熔岩、玄幻、海底和赛博朋克，不加入格斗与回合战的场景池。

玩家一键布阵与 CPU 按近战前排、中程支援和远程后排两翼安排站位。远程普攻在射程内出手，近战技能保留接近要求，并同步调整分工属性与阵容承伤估值。

三模式仍从模式大厅进入。开发文档、角色手册、场景资源检查和打包脚本同步更新，测试覆盖存档展示、首轮结算、远近程行为与完整赛事卡池守恒。

# 1.0.0 · 首次公开源码

发布日期：2026-09-08。

包含抽象格斗、抽象回合战、抽象自走棋三个模式，60 名角色、13 张场景及 18 首程序合成配乐。提供可直接编辑的网页源码、运行素材、开发文档、规则测试与打包脚本。

网页包无需后端即可运行，可部署到 Cloudflare Pages 等静态托管服务。自走棋支持旧赛事存档迁移；浏览器存档不跨域名或设备同步。

自带测试覆盖技能资源规则、综合布阵和缓存等价性，检查脚本验证页面与图片引用。测试范围和操作方式见 [开发指南](DEVELOPMENT.md)。
