CPU 强度中的“抽象”拥有更快反应，会根据威胁方向防御、躲避抓取并选择适合距离的招式。命中、受击与格挡都能积攒能量，100 气释放必杀。轻击命中后可接轻击或重击；技能有独立冷却。贴身抓投可破防，远程弹幕可格挡或跳过。防御槽耗尽会破防。

每局先赢两回合者获胜；2V2 四人同时上场，队内无伤害，全队倒下判负，超时比较全队剩余生命比例。电脑可双人合作打 CPU，或每人带一个 CPU 队友对抗；训练场能量持续补满、对手自动恢复，不计胜负。切换窗口会自动暂停。按左右移动键会改变朝向，停止后保留朝向。可穿过对手，转身攻击。手机支持人机、训练场与单人 2V2，手机端推荐横屏游玩。左侧八向方向盘可按住滑动换向，↖ / ↗ 一键斜跳，朝下为防御；右侧上排是三个专属技能，下排是轻击、重击和必杀。可多指同时按住移动、跳跃和攻击；竖屏招式说明默认折叠，可点开查看，横屏时更大的按键位于画面两侧。

联网对战需两台机器在同一局域网：一方运行 npm run dev（或双击 start.bat）后，双方打开提示的局域网地址。房主创建房间并告知房间码，对手输入房间码点连接加入；场景由房主选择，双方都点再来一局即重开。点「重新选人」会带双方回到选人界面换角色，房间保留，选好后再点开打即可。对手机器上也可以直接用 WASD 移动、J K U I O L 出招（小键盘同样可用）。对手断线会自动重连并从断点继续。不同浏览器之间按容差比对，一般可直接联机，如遇不同步提示请换用相同浏览器。

开打前可选择场景，默认随机；随机模式的再来一局会换地图，同一场对战的各回合保持地图。选角页有固定 BGM，进入场景自动切换对应曲目。首次点击或按键后开始播放，可单独关闭 BGM、调整音量；切到后台或暂停时音乐暂停。

招式根据角色形象与公开梗进行原创演绎，具体效果见选人页。仅含虚构、非血腥的街机战斗。
